# Physics-interpretable reconstruction and event classification

## Objective and comparison

Keep the existing object-level transformer and its joint reconstruction and event objectives. Find physics descriptions that predict the model's response on new events and measure the performance cost of making those descriptions explicit. The separate signal-versus-top reconstruction project has its own worktree.

The sequence below was proposed by the agent and approved for execution by Sid on 27 November. Sampling, thresholds, and model selection below are the agent's implementation choices. This plan precedes the new measurements. June results motivated the hypotheses.

## Experiments

1. **Intervene on ambiguous jets.** Select events with two plausible hadronic W candidates using a stated, fixed rule. Repeat each edit on the same event and object in both models. Move a candidate mass toward the W mass at fixed three-momentum (predict increased W preference for a large-radius jet), change its relative transverse momentum at fixed direction and mass (predict greater W preference), and substitute the tag from a real jet of the same type and similar kinematics (predict that more Higgs-like tagging suppresses its W claim). Include identity edits, counts, score margins, winner swaps, leptonic-channel flips and changes in the joint event score. These are diagnostic interventions on the network, not simulated alternate collisions. Separately alter the relative geometry of the two systems, restore the candidate block-1 head-0 activation from the original event and compare output recovery against other heads and identity restoration. A null or non-specific restoration limits the claimed mechanism.
2. **Test azimuthal symmetry.** Rotate the entire event, including missing momentum, through several fixed angles. Measure changes in individual object labels, whole assignments, signal score and selection at a fixed background working point. Identity rotation is a numerical control. If more than 1% of held-out signal events change an object assignment on average across nonzero angles, prioritise a matched training comparison of ordinary inputs, random global rotation augmentation, and lepton-relative sine/cosine azimuth. Record conventional performance and rotation stability together.
3. **Train and interpret compact students.** Compare the same narrow-message joint architecture trained with labels alone or with labels plus the frozen joint model's soft object and event predictions. Match data, update budget, and seeds. Compare learning curves to distinguish slow convergence from lost capacity. For a useful student, fit a simple expression for one influential scalar on development events and substitute it in the forward pass. Measure truth accuracy, ordinary decision agreement and the held-out intervention dose responses, including the mass and tag controls that broke the earlier formula. Use unseen seeds/events for confirmation. A formula that misses the response is a failed explanation even when ordinary agreement is high.
4. **Classify from reconstructed physics.** Freeze the joint model. Infer W and Higgs candidates identically on signal and background. Fit a small classifier to explicit candidate masses, relative transverse momenta, angular separation, tag evidence and assignment ambiguity. Define missing-candidate indicators. Compare with the native event head, a pooled-representation readout, and the same physics readout with pooled features added. Use the same events and supervision for the fitted readouts. Inspect where the yield gap originates by channel, signal mass, background process and assignment ambiguity. Compare held-out discrimination and tail yields; good AUC alone does not establish equivalent search performance.

## Execution and evaluation

- Start with frozen interventions, the physics readout and the rotation audit. Keep independent arms concurrent where hardware permits. Test the most promising training change across three paired seeds. Use bounded, explicitly labelled pilots before scaling.
- Record Monte Carlo-weighted perfect reconstruction overall and for each of six truth topologies, plus retained signal by mass and reconstructed channel at 200 expected background. Use identical validity selection and dataset yield normalisation across arms. Fit working points on separate data and report the background actually retained on evaluation. Report sparse tail counts and uncertainty where a small pilot cannot resolve the working point.
- Compare paired responses on the same events, retaining zero effects. Check numerical identity controls, per-class output responses, and whether physically matched donors and control heads reproduce the claimed effect. Distinguish a representation that carries information from one used for a decision.
- Reserve a final confirmation split. Log every arm, split, checkpoint, seed, input convention, training budget, failure and change of analysis choice. Link the dated session log and machine-readable results here.
