## Phase 1 — code & methodology audit (reading, before any experiments)

Verified clean (no action needed):
- **A1/A2 mass surgery is physically consistent**: sets `E = sqrt(p² + m²)` at fixed
  3-momentum (`wave1_behavior.py:171`, `wave2_dose_insertion.py:70-72`). pT surgery
  scales all 3 momentum components (direction-preserving) and recomputes E at fixed
  mass. No unphysical 4-vectors.
- **The override-hook math is exact**: per-head out_proj split + bottleneck down/up
  (`interp/activations.py:194-233`) uses weights only — and the trained model itself
  never applies bottleneck biases (the hook IS the bottleneck at train time too), so
  adding `(tgt − s_cur)·w_up` at a position sets that head's scalar to `tgt` exactly.
  The hook chain order (bottleneck hook first, override second) is correct; cached
  `s_cur` is from the live forward.
- **Padding-mask semantics make type→PAD masking clean**: padding enters only as
  `key_padding_mask` (`models/models.py:180`) so a masked object stops influencing
  every other token; its own (ignored) stream survives. Zero rows are forward-safe
  (`nan_to_num` on eta).
- **Split hygiene**: all wave scripts use `is_train=False, n_splits=2,
  validation_split_idx=0, has_eventNumbers=True` → events with eventNumber % 2 == 0
  (`lowleveldataloader.py:185`), the same selection that reproduced the thesis val
  table to 4 s.f. (Phase 0 gate). The interp analyses really are on val data.
- Truth/reco columns (5, -1) are never fed to the model (`model(x[..., :5], types)`);
  donor-row surgeries zero them anyway.
- Thesis model & organism have `is_layer_norm=False` (registry `_BASE_KWARGS`) — the
  "exact logit lens" premise holds architecturally.

Noted (interpretation caveats, not bugs):
- **The 'm' feature the model sees is m², not m** (`models.py:62-72`), in
  (100 GeV)² units. Dose-response x-axes in the logs are labeled in mass but the
  model-side perturbation is quadratic in it (80→125 GeV is Δm²=0.92 units;
  5→80 is Δm²=0.64). Doesn't invalidate anything, but "mass-window" claims are
  really "m²-window".
- **A8's "pT-ranked (87%) ≫ mass-ranked (62%)" has a built-in asymmetry**: both
  candidates are true W-ljets, so their masses differ by little (both ≈ m_W) while
  their pTs differ a lot. Mass-closeness is mechanically a weak predictor on this
  pair distribution even if the model cared about mass. Needs a factorial test
  (→ RT3).
- **E2's "pT ≫ mass ≈ tag" ranking depends on arbitrary perturbation sizes**
  (pT×0.5 vs m→40 vs tag→median). Not standardized per-feature; and "pT" may proxy
  for "pT relative to the event's scale" given the dataset spans 0.8–3 TeV
  resonances (→ RT4).
- **D4-lite swap targets are global class means** → the post-swap state is
  off-manifold by construction (scalar says one channel, rest of stream says the
  other). The 99.8% flip shows the readout uses these scalars; it does NOT by itself
  establish "fully determined by the two wires" (README wording) — no control was
  run for (i) swapping NON-wire scalars, (ii) magnitude-matched random perturbations,
  (iii) clamping the wires while flipping the verdict from the input side (→ RT1, RT2).
- Census→certificate reuse: the wire selection (round 2e) and the D4-lite
  verification ran on overlapping event slices. AUCs ≈0.99 make overfit unlikely,
  but replication on unseen events is cheap (→ folded into RT1).
- Headline rates have no error bars; some strata are small (resolved n≈10³ → ±1-3%
  Wilson at 95%). RT scripts print Wilson CIs.
- B1's "XOR holds (0.96-0.99)" is partly base rates: with skewed marginals,
  XOR-ok is high even under independence. The informative statistic is association
  among borderline/error events (→ RT8, computed alongside RT1).

## Phase 3 — results

### RT6 data hygiene — ALL CLEAN (`redteam_rt6_data.py`)

- eventNumbers are exact integers ≤ 1e6 (well under float32's 2²⁴ — the `% 2` split
  is sound); even fraction 0.4997–0.5018 per DSID.
- Analysis slices are deterministic, **disjoint** (loader consumes indices without
  replenishment) and population-representative: DSID composition of batches 1–6 /
  7–12 / 13–18 matches the full 1.40M-event val population to 3 decimals.
- The waves' ok-filter (exactly 1 ν, exactly 1 lepton) passes **100%** of events —
  no selection bias from it.
- **boosted ∪ resolved exactly partitions qqbb** (0 events in neither, in all three
  slices), and the 77/23 split replicates (76.9% / 76.4% / 77.6% of qqbb).
- Types kinematics re-confirmed: type 3 = LJET (med m 114.5 GeV, pT 535), type 4 =
  SJET (8.9, 62).

### RT1 — wire specificity: the D4-lite certificate SURVIVES, with one wording fix
(`redteam_rt1_wires.py`; thesis model; all on UNSEEN slice C = batches 13-18)

- **Census replicates out-of-sample**: b2h2 AUC 0.9864/0.9961 (truth/pred),
  b1h3 0.9787/0.9896 — identical to round-2e's values from batches 1-12. No
  selection/overfit artifact.
- **Wires-swap replicates**: 99.88% ν flips [Wilson 99.80, 99.93]; single-wire swaps
  match wave-2 exactly (b2h2 alone 61.2% lvbb / 96.0% qqbb; b1h3 alone 6.2%/19.7%).
- **Controls (never run in the waves) all behave**:
  - placebo (own-class means): 0.0000 flips — machinery sound;
  - each of the 10 non-wire scalars swapped individually: ≤ 3.5% flips;
  - the 3 non-wire block-2 scalars swapped jointly: 1.5%;
  - **norm-matched random-direction kick at ν (same L2 as the wire delta, same
    blocks): 2.1%** — the wire swap is NOT a generic big-kick/OOD artifact;
  - kick along non-wire up-projection directions (b1h2+b2h3), norm-matched: 1.4%.
- **The one correction**: "verdict fully determined by the two scalars" is ~95% true,
  not 100% — swapping all 10 non-wire scalars while clamping the wires to their clean
  values still flips 5.25% of ν verdicts (and 4.1% of lep verdicts — note ν's
  perturbed stream propagates to other tokens as a SENDER through later blocks).

### RT2/RT2b — sufficiency direction: wires carry ~80-90% of the verdict flow, and
### the bypass is b2h0+b2h3 (`redteam_rt2_clamp.py`, `redteam_rt2b_bypass.py`)

Flip the verdict from the INPUT side, clamp ν's wires to their clean per-event values:

| intervention (boosted/lvbb, slice C) | ν flip | with ν wires clamped | restoration |
|---|---|---|---|
| surgical truth-W-ljet mask (n=3145) | 0.7717 (replicates round-2c's 77%) | 0.1431 | **81.6%** |
| real-W insertion into lvbb (n=4000) | 0.2950 | 0.0285 | **90.7%** |

- Lepton-side mirror: clamping LEP wires restores lep at 81.4% while ν flips freely —
  the parallel-readers picture again, now from the sufficiency direction.
- **Bypass identified (RT2b)**: clamping wires+b2h0+b2h3 drops residual flips
  0.1431 → 0.0210; +b2h1 adds nothing (0.0197). Clamping all 12 scalars → **0.0000
  exactly**: ν's verdict is architecturally closed over its 12 bottleneck scalars
  (+ own embedding), i.e. there is provably no other path. Corrected statement:
  **b1h3+b2h2 are the primary wires (~80-90% of causal flow); b2h0+b2h3 are real
  secondary carriers (~12%); "fully determined by two scalars" → "by four, two
  dominant".**

### RT3 — factorial winner-take-all: three substantive CORRECTIONS
(`redteam_rt3_wta.py`; both candidates fully controlled (pT, m), tag=−2.6;
original surgically set in place, competitor inserted with foreign direction; n=3143)

Thesis model:

| cell (orig vs ins) | P(orig) | P(ins) | both | orig wins (excl-one) |
|---|---|---|---|---|
| (600,80) vs (300,80) | 0.980 | 0.000 | 0.000 | 1.000 |
| (300,80) vs (600,60) | 0.020 | 0.892 | 0.011 | 0.011 |
| **(600,80) vs (600,80) tie** | **0.937** | **0.772** | **0.746** | **0.879** |
| (450,80) vs (450,110) | 0.925 | 0.001 | 0.001 | 1.000 |
| **(450,80) vs (600,110)** | **0.896** | **0.092** | 0.084 | **0.990** |

1. **"pT-ranked" only holds at tied or low-side mass.** A (pT 600, m 110) candidate
   LOSES ~90/10 to (pT 450, m 80), while (pT 600, m 60) BEATS (pT 300, m 80) ~99/1.
   The mass penalty is strongly asymmetric: H-ward masses are heavily penalised
   (likely token-level competition with the H class), low-side masses barely. A8's
   "higher-pT wins 87% vs closer-mass 62%" comparison was uninformative — its two
   real W-jets had near-degenerate masses by construction.
2. **Exclusivity is emergent ranking, NOT an enforced exactly-one constraint**:
   identical candidates BOTH claim W in 74.6% of events (A8 saw "both" ≤ 2.7% only
   because real W pairs always differ in pT). Lateral-inhibition mechanisms for
   Stage B should expect score-gap-driven suppression, not hard exclusion.
3. **"Direction-blind" fails under competition**: in the symmetric tie the in-event-
   coherent original beats the foreign-direction insert 87.9/12.1 (and 0.937 vs
   0.772 marginal). Solo φ/η insensitivity (E2, round-1) is real but does not
   transfer to the competitive setting.

Organism (`--model ent1-d20-2blk`): tie-cell exclusivity failure replicates (both
claim 74.1%) but the coherence edge nearly vanishes (57.5/42.5), and cells h/i
**invert** — (600,110) beats (450,80) 0.726/0.379 — pT dominates even H-ward.
**Wave-1's "the candidacy FEATURE diverges across scale" extends to the competition
rule**; organism-derived Stage-B findings about the score function won't transfer.

### RT4 — "pT-gated" is largely RELATIVE event-hardness, not absolute pT
(`redteam_rt4_relpt.py`; boosted, slice C)

| arm | thesis P(W claims) | organism |
|---|---|---|
| baseline | 0.924 | 0.884 |
| (a) W ×0.5 | 0.486 | 0.492 |
| (b) whole event ×0.5 | 0.749 | 0.805 |
| (c) rest ×2 (W untouched) | **0.573** | **0.505** |
| (d) rest ×0.5 (W untouched) | 0.970 | 0.959 |

Doubling everything EXCEPT the W costs it 35-38pp of claim rate without touching it;
halving the whole event costs only 12-18pp (vs 43-39pp for halving the W alone).
Observationally: a fixed 300-500 GeV W claims at 0.91/0.84 (thesis/organism) in
0.8 TeV events but only ~0.73/0.63 at 2 TeV. **The candidacy score reads the W's
hardness relative to the event, in BOTH models** — this also reframes B3's "misses
are soft W-jets" (soft *for their event*). E2's occlusion ranking ("pT ≫ mass ≈
tag") additionally conflates non-standardised perturbation sizes.

### RT8 — B1's "XOR holds" was mostly base rates

Independence null already gives XOR-ok 0.945/0.910/0.721 (lvbb/boosted/resolved) vs
observed 0.991/0.975/0.930. The structure is real but the right statistic is the
association: φ = −0.83/−0.73/−0.76. Report φ (or odds ratios / error-event XOR),
not raw XOR-ok.

## Verdict

**The core circuit account survives hard adversarial testing.** Split/data hygiene
is clean; the wire census replicates out-of-sample; the D4-lite swap is wire-specific
(placebo 0, norm-matched random kick 2%); parallel-readers is confirmed in both
causal directions; the surgical-mask and insertion behavioral numbers replicate on
unseen events.

**Corrections to adopt** (ordered by importance):
1. Candidacy is **relative** event-hardness, not absolute pT (RT4) — affects how E4
   PySR extraction should be set up (include event-context features, not just
   per-jet kinematics).
2. Winner-take-all = soft score ranking; **no enforced exclusivity** (ties → both
   claim); thesis-model ranking is mass-window-dominated on the H-ward side,
   pT-dominated elsewhere; coherence/direction matters under competition (RT3).
   Stage-B preregistrations should be updated before running.
3. "Fully determined by two scalars" → **two primary + two secondary wires**
   (b2h0/b2h3 carry ~12% of mask-flip flow); "all 12 scalars" is the architecturally
   closed set (RT2/RT2b).
4. The organism diverges from the thesis model in the competition rule, not just the
   solo mass curve (RT3) — be careful transferring Stage-B mechanism findings.
5. Cosmetic: report φ not XOR-ok (RT8); the model's mass feature is m² (models.py:62)
   so "mass-window" = m²-window; A8's pT-vs-mass comparison should be retired in
   favour of RT3-style factorials.

## Learnings (methodology, promote where useful)

- **Class-mean-overwrite certificates need three controls**: placebo (own-class),
  non-target channels swapped, and a norm-matched random-direction kick. Here they
  cost ~4 extra configs and turned "looks causal" into "is causal".
- **Necessity-style swaps overstate exclusivity; run the clamp-under-input-flip
  (sufficiency) direction too.** "Swap flips 99.9%" coexisted with "clamp only
  restores 82%".
- **Competition amplifies features that solo dose-responses miss** (direction
  coherence: invisible solo, 88/12 under a tie). Test candidate-scoring claims with
  factorial two-candidate designs, not single-candidate doses.
- **For any "feature X dominates" claim, test relative vs absolute** by scaling the
  complement (rest ×2 at fixed target) — three extra forward passes.
- The proportional loader consumes indices without replenishment → `next(dl)` slices
  are disjoint by construction; batches 13-18 are a free held-out set for any
  follow-up (waves used 1-12).
- eventNumbers are stored as float32 but are ≤ 1e6, so the parity split is exact —
  checked once, never worry again (would silently break above 2²⁴).
