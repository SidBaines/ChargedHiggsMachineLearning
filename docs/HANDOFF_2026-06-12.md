## 2. The science — what is established (all on fresh val slices, replicated)

Read `experiments/h1_narrative.ipynb` for the full claims/evidence/confidence
scoreboard. One-paragraph version: **the reconstruction transformer decides the
channel by having every system score "am I the W?" against the context it sees**
— each jet computes candidacy = relative-hardness × m²-window × anti-tag (blocks
0-1 absorb context; constitutively relational — no context ⇒ no claim); the
leptonic system is scored by the same principle (b1h3 ≈ −4.57·tanh(pT(lepW)/HT)
+1.25, R²=0.84); claims are score-ranked with EMERGENT exclusivity (no
inhibition edge — each jet suppresses only ITSELF via its own read of rivals;
thesis comparator = b2h2, the same head that broadcasts the verdict); lep+ν
inherit through a closed wire set (b2h2+b1h3 ~85%, b2h0/h3 ~12%). Cross-system
threshold: a hadronic candidate needs ~1.4× the leptonic-W pT to steal a true
lvbb event (organism: ~1.25×).
